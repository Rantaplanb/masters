# Application action plan

The official deadline is Monday, 21 September 2026.
The internal submission target is Monday, 14 September 2026.
This leaves one week for resolving payment, portal, referee, or interview-invitation problems.

## 1. Start the portal application - 23-24 August

- [ ] Open <https://apply.ponts.academy/enter/131>.
- [ ] Select the MSc in Advanced Cybersecurity Technologies and Governance.
- [ ] Create and activate the applicant account with an email address checked every day.
- [ ] Review every portal task before entering final information.
- [ ] Record the required fields, document formats, size limits, and task statuses.
- [ ] Record how referee invitations are triggered and whether the portal shows a separate referee deadline.
- [ ] Confirm the accepted English-language evidence and any translation or certification requirements.
- [ ] Save the application and confirm that it can be reopened successfully.

## 2. Secure the referees - by 28 August

- [ ] Ask one current or recent manager for a strong confidential recommendation.
- [ ] Ask the bachelor's thesis supervisor if they remember the work well enough to provide a strong and specific recommendation.
- [ ] If the academic response is vague, hesitant, or unavailable, ask a second manager with a complementary perspective.
- [ ] Identify one backup referee.
- [ ] Collect each referee's full name, title, organization, professional email, telephone number, and relationship to you.
- [ ] Send each confirmed referee the CV, programme link, motivation summary, relevant achievements they directly observed, and available instructions.
- [ ] Tell each referee the official application deadline and forward their exact submission deadline when the portal provides it.

The strongest pairing is one strong manager plus a strong thesis supervisor.
Two strong managers are better than using an academic referee who can provide only a generic letter.
